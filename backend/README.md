# SANKAT-SETU Backend (V0.3 data backbone)

FastAPI service providing the auditable, provenance-tracked data backbone
behind the SANKAT-SETU frontend. See `/V0_3_MERGE_NOTES.md` at the repo root
for what was added/changed and why.

## Setup

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Run (SQLite, zero external services)

```bash
uvicorn app.main:app --reload --port 8000
```

The app seeds the deterministic Uttarakhand demo scenario
(`uttarakhand-flashflood-demo`) on startup. Open http://localhost:8000/docs
for interactive OpenAPI docs.

## Run against Postgres/PostGIS instead

```bash
# in .env:
DATABASE_URL=postgresql+psycopg://user:pass@localhost:5432/sankatsetu
alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

## Migrations

```bash
alembic upgrade head          # apply
alembic revision --autogenerate -m "message"   # generate a new one after model changes
```

Note: `alembic/versions/0001_initial.py` in this repo was hand-written
(field-for-field, matching `app/models/*.py`) rather than autogenerated,
because this development sandbox has no network access to install the
`alembic` package. Run `alembic check` locally after `pip install -r
requirements.txt` to confirm it actually matches the models before relying
on it against a real database.

## Design notes

- **SQLite by default, Postgres/PostGIS-ready.** Geometry is stored as
  lat/lon floats + GeoJSON text rather than a native PostGIS column, so the
  same models run on SQLite for local dev/tests. See
  `app/models/base.py:GeoPointMixin` for the migration path.
- **Provenance is mandatory**, not optional, on every critical record —
  `app/models/base.py:ProvenanceMixin`. `is_simulated` defaults to `True`
  and is only cleared by a real manual verification
  (`POST /assets/{id}/verify`).
- **Freshness and confidence are deterministic, not ML** —
  `app/services/freshness_service.py`, `app/services/confidence_service.py`.
  Thresholds and weights live in `app/core/config.py`, not hardcoded per
  caller.
- **Conflicts are surfaced, never silently resolved** —
  `app/services/conflict_service.py`.
